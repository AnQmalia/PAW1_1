# Running the project

This is a static HTML, CSS, and JavaScript project with no package dependencies.

Use the Run button to start the `Start application` workflow:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the Replit preview to view the page. The click exercise displays the numbers
1 through 9. Phone-number validation and drag-and-drop are not yet implemented.
